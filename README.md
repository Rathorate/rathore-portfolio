# Rathore Portfolio

A single-file, dark hacker/matrix-themed personal portfolio website — built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step, no dependencies.

## 🚀 Live Demo
[View live site](https://rathore-portfolio.vercel.app)

## ✨ Features
- Animated matrix rain background (canvas)
- Custom cursor with hover interactions
- Typing animation for hero roles
- Scroll-triggered reveal animations
- Fixed navbar with active-section highlighting
- Scrolling tech skills ticker
- Filterable blog grid
- Sticky skills navigation with animated progress bars
- Fully responsive with mobile hamburger menu
- Contact form (opens via mailto)
- SEO: Open Graph, Twitter Card, JSON-LD Person schema

## 🛠️ Tech Stack
HTML5, CSS3, Vanilla JavaScript — no external libraries.

## 📦 Getting Started
Clone the repo and serve it locally:

\`\`\`bash
git clone https://github.com/rathorate/rathore-portfolio.git
cd rathore-portfolio
python3 -m http.server 8000
\`\`\`

Then open http://localhost:8000 in your browser.

## 🚢 Deployment
Deployed on Vercel. To deploy your own copy:

\`\`\`bash
npx vercel
\`\`\`
